# Program 8: Sorting Algorithms with Comparison and Swap Count

## 1. Data Structure Definition
An array is used to store N randomly generated integers in the range [1,1000].

## 2. Description of Sorting Algorithms

- Bubble Sort  
  Compares adjacent elements and swaps if needed.

- Selection Sort  
  Finds minimum element and places it in correct position.

- Insertion Sort  
  Inserts each element into its proper position in sorted portion.

- Merge Sort  
  Uses divide and conquer strategy to sort the array.

## 3. Overview of main()
The program generates N random numbers and displays them.
The user selects a sorting algorithm.
The program sorts the array and displays:
- Sorted numbers
- Total comparisons
- Total swaps (if applicable)

## 4. Sample Output
```
Enter value of N: 5

Numbers before sorting:
523 121 987 342 200

Choose sorting algorithm:

Bubble Sort

Selection Sort

Insertion Sort

Merge Sort
1

Numbers after sorting:
121 200 342 523 987

Total Comparisons: 10
Total Swaps: 6
```

## 5. Conclusion
This program demonstrates multiple sorting techniques and compares their performance based on number of comparisons and swaps.
