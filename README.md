

# DSA Assignment Repository

## Data Structures and Algorithms – COMP 202

This repository includes all coursework assignments completed for the **COMP 202: Data Structures and Algorithms** subject.

All implementations are written in **C programming language** and are arranged according to their respective question numbers. The main objective of this repository is to **build, practice, and showcase essential data structure and algorithm concepts**, such as stacks, queues, linked lists, trees, graphs, heaps, and various sorting methods.

---

## Repository Organization

Each solution is stored in an individual C source file named in the format:

`prog_<question_number>.c`

For explanation and reference, corresponding documentation files are provided in Markdown format using the naming convention:

`doc_<question_number>.md`

This structure ensures clarity, easy navigation, and proper organization of all assignments.
